INSTALL (SAFE NA PARAAN)
1. I-STOP muna ang Node server.
2. BACKUP ang buong project folder mo. Lalo na ang server.js, public/index.html, at data/.
3. I-extract ang ZIP sa project root (kung nasaan ang server.js). Pumayag sa overwrite ng server.js at public/index.html.
4. PANATILIHIN ang dati mong data/ folder. HUWAG burahin o palitan ang data/state.json at data/settings.json.
5. Siguraduhing may CEO password sa data/settings.json (field na password) o environment variable na CEO_PASSWORD. Wala nang built-in default na "cyborg". Kapag walang naka-configure na password, naka-lock ang CEO/admin API.
6. I-double-click ang APPLY-PHASE-D.bat.
7. Simulan ulit: node server.js. I-refresh ang browser.

PAALALA SA BAZAAR LOGIN
Sa unang start, papalitan ng random secret ang lumang hard-coded cookie key. Kailangan mag-Facebook login ulit ang Bazaar visitors nang isang beses. Ise-save ang bagong secret sa data/state.json para manatiling valid ang cookie sa normal na restart. HUWAG burahin ang data/state.json.

MGA INAYOS SA SERVER
- Hindi na awtomatikong BAYAD NA ang order sa pag-click ng checkout. Pending muna ito.
- Server ang nagva-validate ng item ID at presyo; hindi pinagkakatiwalaan ang presyo mula sa browser.
- May idempotency key ang checkout para hindi madoble ang order sa network retry.
- Hindi na public ang order history.
- May Mall Orders — Payment Review sa CEO > AD PROJECTS & GOODS. I-verify lang kapag nakita at nasuri mo ang totoong payment receipt/reference.
- Walang payment gateway na konektado. Manual CEO verification lang ito, hindi automatic bank/GCash/Shopee verification.
- Referral commission at order quest reward ay pagkatapos lang ng manual payment verification; hindi nadodoble kapag inulit ang verify.
- Hindi na puwedeng gamitin ang generic task endpoint para i-claim ang check-in/order/share/content reward.
- Random na ang demo visitor ID; hindi na puwedeng manghula ng account gamit lang ang display name.
- Random at persisted na ang Bazaar cookie-signing secret; constant-time ang signature comparison.
- Hindi na nawawala ang CEO password/Facebook/Shopee credentials kapag nagse-save ng AI provider settings.
- Disabled ang account/provider GET endpoints na dating nangangailangan ng password sa URL.
- May baseline security headers at order rate limit.

HINDI PA NAPATUNAYAN
- Hindi pa nasusubukan sa totoong Windows PC o pisikal na cellphone.
- Walang tunay na payment gateway.
- Wala pang 2FA. Password gate lang ito, hindi two-factor authentication.
- Ang campaign/social share reward ay nangangailangan pa ng trusted social-network callback o manual approval para maging fraud-resistant.
- JSON file storage pa rin ang database; hindi pa ito transactional multi-user database.
